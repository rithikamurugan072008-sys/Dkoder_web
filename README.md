# Dkoder — The Placement LMS for Engineering Colleges

> Real Placement Questions & Live Coding Sandbox for Campus Recruitment

Dkoder helps engineering students crack their dream campus placements by narrowing the gap between preparation and actual company patterns (Zoho, TCS, Amazon, Infosys, Cognizant, etc.).

---

## 🎨 Theme & Highlights
- **Vibrant Yellow & Purple Design**: Modern aesthetic with deep purple luxury surfaces (`#12052B`, `#1E0D47`) and radiant yellow accents (`#FCC419`).
- **Interactive Front Page**: Dual-column showcase with ambient radial lighting and real-time Placement Intelligence Bot tabs.
- **Curated Company Repositories**: Real interview questions categorized by package tiers (Mass, Dream, Super Dream).
- **Interactive Coding Practice Arena**: Pair coding sandbox, language switchers, and real test-case runners.
- **Mental Clarity & Anxiety Elimination**: Targeted solutions for common interview worries (aptitude speed, DSA anxiety, resume shortlisting).
- **Institutional LMS Partnership**: Custom Institutional MoU onboarding portal for engineering universities.

---

## 🚀 Getting Started

Simply open `index.html` in any web browser, or run a local web server:

### Option 1: Direct File
Open `index.html` directly in Chrome, Edge, Brave, or Firefox.

### Option 2: Local HTTP Server
Using Python:
```bash
python -m http.server 3000
```
Then navigate to `http://localhost:3000` in your browser.
